# Directory reorganization (Tier 1 + 2), dist/ tracked, English-only handbook in the lite mirror

**Type:** Refactor / structure
**Model:** Opus — cross-cutting moves that touch the root lookup, the installer staging list, the
test copy rules, the lite mirror and ~40 docs; each runtime path was traced to its call sites first.

## Summary

The root had ~25 entries mixing generator assets, samples, runtime output, docs and plans. The
author approved Tier 1 + 2 and rejected Tier 3 (one `workspace/` folder): `prompts/`, `out/`,
`logs/` stay at the root. `prompts/` is the author's container of every project's spec + seed.

**Tier 1 — housekeeping (no runtime paths):**
- `.playwright-mcp/` gitignored; stray root `dps-nn.log.jsonl` deleted.
- Finished plans → `plan/archive/`: `codebase-map`, `dps-nn-session3-handover`,
  `task-a-doc-architecture`, `v6-task-breakdown`, `dps-nn-6.5.0-spec`.
- `docs/01-tutorial-genesis.md` → `docs/tutorial/genesis.md` (all four Diataxis types now folders).

**Tier 2 — generator assets grouped under `templates/`:**
- `feature-templates/` → `templates/features/`; `images/` → `templates/static/`.
  `spec.schema.json` stays at the root: with `templates/` it is the GenesisRoot marker
  (`Program.cs`, `Doctor.cs`, `gui/src/main/paths.ts`).
- `handbook2/` → `docs/handbook/` (`D` in `build-handbook2.py`; the three `../docs/` links in ch08
  became `../`).

**dist/ and the lite mirror (author's request):**
- `/dist/` removed from `.gitignore`: the built handbook PDFs are tracked in the full repo.
  `/build/` (intermediates) stays ignored. The PDFs are ordinary git blobs (~7 MB now), not LFS.
- `scripts/lite-tree.py`: the lite edition gets the English handbook only — drops
  `docs/handbook/{bg,de,trump,trump-bg}/` and every `dist/` PDF except `dps-nn-handbook-v2.pdf`.
  The first-edition `dps-nn-handbook.pdf` is not committed at all (author: keep only edition 2);
  CI's `handbook.yml` still builds it as a release asset. The build scripts (which carry the LaTeX header/cover/filters) stay.

**Also:** finished changelog 141's doc sweep, covering the stale preset/verify lines flagged by the
other session: en 01, 15, 24, 25 and de 15, 24, 25.

## Techniques

- Every moved path traced to its readers before moving:
  - `Program.cs` (2 call sites);
  - `BuildStages.CopyStaticAssets`;
  - the test project (the `feature-templates\**` copy rule was dropped, since `templates\**`
    already covers it);
  - the CoreTests paths;
  - `gui/scripts/stage-genesis.mjs` (the `'feature-templates'` and `'images'` entries were dropped,
    since `'templates'` covers both).
- `gui/src/main/paths.ts`: **comment only**, no behaviour change.
- Stale `feature-templates/` + `images/` copies deleted from the test bin folder before testing, so
  the run could not pass on leftovers.
- History left as history: older changelogs, `plan/state*.md` and `plan/decisions.md` keep the old
  paths.

## Not touched

- **bg and trump-bg handbook text** (author's rule): these still say `feature-templates/`, and
  trump-bg ch00 says `docs/01-tutorial-genesis.md`.
- `docs/reference/file-map.md`: generated by `generate-file-map.ps1`, and pwsh is not installed
  here. Regenerate it on Windows.
- **PDFs were not rebuilt:** another session was building into the shared `build/handbook/` at the
  same time. The en/de/xx/trump PDFs predate the path-string edits; rebuild them once that session
  is done.
